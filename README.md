## 下单前这三件事必须确认

**第一，用测试IP验证线路是否合适**

不同运营商、不同地区的网络环境差异很大。下单前先用测试IP在本地ping和traceroute，看延迟和路由是否符合预期。

电信用户重点看有没有走CN2。用`traceroute 72.249.202.166`（CN2 GIA测试IP），如果路由中出现59.43开头的IP段，说明确实在用CN2线路。如果全程202.97开头，那是普通163线路。

联通用户看是否经过AS9929节点。用`traceroute 38.34.13.1`（洛杉矶CUII测试IP），路由中如果有219.158开头的IP或AS9929标识，说明走的是联通优化线路。

如果本地环境不方便测试，可以用国内的多地ping工具（搜索"多地ping"能找到免费服务），同时测试电信、联通、移动三网的延迟和丢包率。

**第二，确认流量是否够用**

月流量是自然月统计，不是30天滚动周期。如果每月15号开通，那么15号到月底这半个月和下个月1号到14号分别是两个计费周期。跨月使用要注意流量分配。

超流量后如何处理，资料中没有明确说明。通常有三种做法：限速到1-10Mbps、暂停服务到下个计费周期、或者按量计费。下单前最好在工单或客服渠道确认一下具体政策，避免流量用完后措手不及。

**第三，搞清楚退款条件**

ZoroCloud的美国CN2 GIA系列和洛杉矶CUII系列标注支持24小时退款，但有两个细节：

退款通常要求你没有违反使用条款。如果开通后立刻跑满带宽测速、大量发包或触发滥用检测，商家有权拒绝退款。

"24小时"指的是从开通时间算起，不是从你决定退款的时候算。如果你周五下午开通，周一早上才发现线路不合适想退，已经超过24小时了。
